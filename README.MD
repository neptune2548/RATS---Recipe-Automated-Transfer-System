# Master Recipe Command Center V0.1

ระบบศูนย์กลางสำหรับจัดการและควบคุมสูตร (Recipe) ของเครื่องจักร รองรับการตรวจสอบสถานะ, ดึง (Pull) และส่ง (Push) โปรแกรมผ่านโปรโตคอล SECS/GEM พร้อมหน้า UI แสดงผลสถานะแบบ Real-time

## สิ่งที่ต้องมีก่อนใช้งาน (Prerequisites)
1. Python 3.11 (หรือเวอร์ชันที่ใกล้เคียง)
2. ติดตั้ง Library ที่จำเป็นทั้งหมด โดยพิมพ์คำสั่งนี้ใน Terminal:
   ```bash
   pip install -r requirements.txt

How to run
วิธีที่ 1: รันผ่านสคริปต์ (แนะนำสำหรับผู้ใช้ทั่วไป)

ดับเบิลคลิกที่ไฟล์ start_server.bat

ระบบจะทำการสตาร์ทเซิร์ฟเวอร์ และเด้งหน้าเบราว์เซอร์ขึ้นมาให้เองโดยอัตโนมัติ

วิธีที่ 2: รันผ่าน Terminal สำหรับนักพัฒนา
    -เข้าที่อยู่ไฟล์ที่โหลดมาเก็บไว้
    -เปิด Terminal และรันสคริปต์ python -main.py
    (เซิร์ฟเวอร์จะรันที่พอร์ต 8080 และเปิดเบราว์เซอร์ไปที่ http://127.0.0.1:8080 อัตโนมัติใน 2 วินาที)
